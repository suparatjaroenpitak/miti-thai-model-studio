# การเรียก Blender API ด้วยภาษาไทย

`engine/thai_api.py` เป็นชั้นแปลงชื่อภาษาไทยไปยัง API ของ Blender ที่ติดตั้งจริง ไม่ได้จำลองผลการทำงานหรือสร้าง modeling kernel อีกชุด สคริปต์ยังใช้ `import bpy`, `bmesh` และ `mathutils` โดยตรงได้ตามเดิม

## คำสั่งของ Blender

```python
คำสั่ง("ตาข่าย.เพิ่มลูกบาศก์", ขนาด=2, ตำแหน่ง=(0, 0, 1))
# เรียกด้วยรหัส API ต้นฉบับก็ได้
คำสั่ง("bpy.ops.mesh.primitive_cube_add", size=2, location=(3, 0, 1))
```

`คำสั่ง` และ `เรียก` รับรหัส `bpy.ops` เต็ม ชื่อย่อ `mesh.primitive_cube_add` หรือชื่อไทยที่ไม่ซ้ำจากคลังคำสั่ง พารามิเตอร์และ enum แปลงกลับเป็น ID ของ Blender จาก metadata เช่นเดียวกัน รหัส API อังกฤษมีลำดับก่อนคำแปลที่แสดงผล และรหัสภาษาไทย `thaiIdentifier` ที่แยกคำซ้ำแล้วมีลำดับก่อนชื่อแสดงผล

คืนค่าเดิมจาก Blender เช่น `{'FINISHED'}` หรือ `{'CANCELLED'}` คำสั่งที่ต้องใช้ editor, mode หรือหน้าต่าง Blender อาจทำงานไม่ได้ใน background process ข้อผิดพลาดเดิมยังแสดงพร้อมหมายเหตุภาษาไทยระบุ context

## ข้อมูลและฟังก์ชันของวัตถุ

```python
วัตถุ = ของจริง(เบลนเดอร์.บริบท.วัตถุ)
ตั้งค่า(วัตถุ, ชื่อ="กล่องไทย", ตำแหน่ง=(1, 2, 1))
print(อ่านค่า(วัตถุ, "ชื่อ"))

วัสดุใหม่ = เบลนเดอร์.ข้อมูล.วัสดุ.สร้าง(ชื่อ="วัสดุใหม่")
ตั้งค่า(วัสดุใหม่, ใช้โหนด=True)
วัตถุ.data.materials.append(วัสดุใหม่)

เมชใหม่ = เรียกฟังก์ชัน(bpy.data.meshes, "สร้าง", ชื่อ="เมชใหม่")
วัตถุใหม่ = เรียกAPI("bpy.data.objects.new", ชื่อ="วัตถุใหม่", ข้อมูลวัตถุ=เมชใหม่)
เรียกฟังก์ชัน(bpy.context.scene.collection.objects, "เชื่อม", วัตถุใหม่)
```

`ไทย(เป้าหมาย)` ใช้ชื่อสมาชิกไทยเพื่ออ่านและตั้งค่า เช่น `ไทย(วัตถุ).ตำแหน่ง = (0, 0, 2)` โดยยังรองรับชื่อสมาชิกอังกฤษเดิม Proxy ใช้เฉพาะการนำทางข้อมูล การเรียกฟังก์ชันและการเข้าถึงสมาชิก collection คืน Blender object จริง จึงใช้ต่อกับ `bpy` ได้ ไม่เปลี่ยน identity ของวัตถุที่คืนจากฟังก์ชัน

ใช้ `ของจริง(proxy)` หรือ `proxy.ต้นฉบับ` เมื่อต้องการ object ต้นฉบับจากการนำทาง เช่น `เบลนเดอร์.บริบท.วัตถุ` ค่าตัวเลข tuple และ Vector คืนชนิดข้อมูลเดิม

## API โมดูลอื่น

```python
bm = เรียกAPI("bmesh.new")
เรียกAPI("bmesh.ops.create_cube", bm, size=1)
bm.free()
เวกเตอร์ = เรียกAPI("mathutils.Vector", (1, 2, 3))
```

`เรียกAPI` รองรับเส้นทาง public ใน `bpy`, `bmesh`, `mathutils`, `gpu`, `gpu_extras`, `bpy_extras`, `blf`, `aud` และ `idprop` พร้อม import submodule ที่ยังไม่ได้โหลด โมดูลหรือฟังก์ชันที่ต้องใช้ GPU/เสียง/UI context ยังต้องมีเงื่อนไขนั้นจริง

## ค้นหาและขอบเขต

```python
รายการ = ค้นหาคำสั่ง("ลูกบาศก์", limit=20)
ข้อมูล = ข้อมูลคลังคำสั่ง()
```

คลังอ่านจากพาธใน environment `MITI_API_CATALOG` หากไฟล์นั้นมีอยู่ ไม่เช่นนั้นใช้ `engine/blender_api.json` โดยโหลดเมื่อมีการเรียกใช้งาน ระบบเก็บ ID ต้นฉบับและ provenance คำแปลไว้ ไม่อ้างว่าคำแปลที่สร้างเพิ่มเป็นคำแปลทางการของ Blender

หากชื่อแสดงผลซ้ำและไม่มีรหัสไทยที่ระบุชัด ระบบแจ้งชื่อที่กำกวมแทนการเดาว่าต้องเรียกอะไร ใช้ `thaiIdentifier`/`thaiPath` ที่แสดงในคลัง หรือ ID อังกฤษเต็มเพื่อระบุเจาะจง

ข้อมูลในคลังคือ API ที่ introspect ได้จาก build ที่ตรวจ ไม่เท่ากับทุก native function ภายใน Blender ส่วน API ที่เปิดเผยยังเข้าถึงผ่านชื่อเดิมได้ แม้ยังไม่มีคำแปลที่สมบูรณ์ ไม่มีการปิดกั้นหรือแทนที่ API ด้วยผลจำลอง

## ทดสอบ

รัน `tests/ThaiApiSmoke.py` ใน Blender process ใหม่ด้วย `--background --factory-startup --python-exit-code 1` ทดสอบการสร้างโมเดลภาษาไทย, properties, proxy, material, RNA methods, bmesh, mathutils และข้อผิดพลาด
