# คลัง API ของ Blender ภาษาไทย — มิติ สตูดิโอ 0.2

ใช้ **คลัง Blender ภาษาไทย** ทางซ้าย หรือ **Ctrl+Space** ค้นหาได้ทั้งชื่อไทย ชื่อต้นฉบับ และรหัส API เลือกแถวแล้วกำหนดพารามิเตอร์ กด **แทรกโค้ดที่เลือก** จากนั้นกด F5 เพื่อรันด้วย Blender จริง

## รายการที่ดึงจาก Blender 5.2.2 LTS

| ประเภท | จำนวน |
| --- | ---: |
| คำสั่ง `bpy.ops` | 2,499 |
| ชนิดข้อมูล RNA | 4,012 |
| คุณสมบัติที่ประกาศในชนิดข้อมูล | 10,159 |
| เมธอด RNA และเมธอด Python/native ที่เปิดเผยของชนิดข้อมูล | 5,234 |
| ฟังก์ชันและ constructor ในโมดูลที่สำรวจ | 785 |
| รวม ID ที่ไม่ซ้ำ | **22,689** |

โมดูล/ออบเจกต์ที่สำรวจ 36 จุด รวม `bpy.context`, `bpy.data`, `bpy.app`, `bpy.utils`, `bpy.props`, `bpy.path`, `bpy.msgbus`, `bmesh`, `mathutils`, `gpu`, `blf`, `aud` และโมดูลย่อยตาม `coverage.moduleNames` ในไฟล์ข้อมูล

แต่ละรายการเก็บชื่อไทย ชื่อต้นฉบับ คำอธิบาย ประเภท พารามิเตอร์ ค่าเริ่มต้น ตัวเลือก enum และ ID อ้างอิงตามที่ API เปิดเผย มี enum metadata รวม 38,949 รายการในโครงสร้างต่าง ๆ

ชื่อหลักของทั้ง 22,689 รายการมีภาษาไทย ตรวจด้วยสคริปต์ ส่วนชื่อพารามิเตอร์และตัวเลือกใช้คำแปล/อภิธานศัพท์ตามข้อมูลที่มี ค่าทางเทคนิค เช่นตัวอักษรแป้นพิมพ์ รหัสรูปแบบไฟล์ และชื่อมาตรฐานอาจยังแสดงรหัสเดิม

## โค้ดที่เรียกฟังก์ชันจริง

```python
ล้างฉาก()
คำสั่ง("ตาข่าย.เพิ่มลูกบาศก์", ขนาด=2, ตำแหน่ง=(0, 0, 1))
กล่องที่สร้าง = ของจริง(เบลนเดอร์.บริบท.วัตถุ)
ตั้งค่า(กล่องที่สร้าง, ชื่อ="กล่องไทย", ตำแหน่ง=(1, 2, 1))
```

ชื่ออ้างอิงภาษาไทย `thaiPath` และพารามิเตอร์ `thaiIdentifier` สร้างให้ไม่ชนกันหลัง normalize ตามกฎของ Python และ runtime เช่น Size กับ Scale ที่คำแปลเดิมอาจเป็น “ขนาด” เหมือนกัน ใช้ `ขนาด` กับ `ขนาด_2` เพื่อระบุชัดเจน ID อังกฤษยังใช้ได้โดยตรง

สำหรับเมธอด/คุณสมบัติ ให้ระบุตัวแปรเป้าหมาย เช่น mesh, object หรือ material ที่สร้างไว้ในโค้ด ระบบไม่สร้างตัวแปร `เป้าหมาย` ให้เอง พารามิเตอร์ที่รับ mesh/collection/vector ต้องใส่ข้อมูลชนิดนั้นจริง ช่องค่าในหน้าคลังใช้ไวยากรณ์ Python

```python
เมช = เบลนเดอร์.ข้อมูล.ตาข่าย.สร้าง(ชื่อ="สามเหลี่ยม")
เรียกฟังก์ชัน(เมช, "from_pydata",
    vertices=[(0, 0, 0), (1, 0, 0), (0, 1, 0)],
    edges=[], faces=[(0, 1, 2)])
```

หน้าคลังจะแทรกชื่อเมธอดและพารามิเตอร์ไทยที่แน่นอนจาก metadata ให้ ใช้ชื่อเดิมอย่างตัวอย่างนี้เพื่อตรวจเทียบกับ API ได้ด้วย ฟังก์ชันโมดูลที่ไม่มี schema พารามิเตอร์ใช้ช่องอาร์กิวเมนต์ตามตำแหน่งและคำอธิบายต้นฉบับ

## บริบทของคำสั่ง

การสำรวจไม่ได้รันคำสั่งทั้งหมด คำสั่งทั้ง 2,499 รายการถูกตรวจ `poll()` แบบอ่านสถานะในฉากเริ่มต้น: ผ่าน 672 รายการ และต้องเตรียมบริบท 1,827 รายการ ตัวเลขนี้ไม่ใช่จำนวนคำสั่งที่เอนจินรองรับหรือไม่รองรับ

- คำสั่ง edit mesh ต้องมี mesh และเข้า Edit Mode
- คำสั่ง sculpt/pose/node ต้องมีข้อมูลและโหมดที่ตรงกัน
- คำสั่งที่ต้องมีหน้าต่าง เลือก **โมเดล → ใช้บริบทหน้าต่าง Blender ขณะรัน** โดยเริ่มในพื้นที่ VIEW_3D
- พื้นที่ทำงานชนิดอื่นใช้ `bpy.context.temp_override(...)` หรือ API ภาษาไทยที่เทียบเท่า เพื่อระบุบริบทที่ต้องการ
- คำสั่งแบบ modal/INVOKE อาจต้องรอผู้ใช้ในหน้าต่าง จึงไม่เท่ากับการรันคำสั่ง synchronous แล้วจบงาน
- เปิดไฟล์ผลลัพธ์ใน Blender เพื่อใช้หน้าต่างครบชุดได้ เมนูคำสั่งเปิดนี้จะตั้งภาษาไทยเฉพาะ process ที่เปิด

โหมดหน้าต่างเปิด process ใหม่ ปิดหลังสร้างและบันทึกเสร็จ ปุ่มหยุด/Escape ยกเลิก process ของงานนั้น ไม่แตะฉากใน Blender process อื่น

## ที่มาคำแปล

- `official` — คำแปลที่มีอยู่ใน `locale/th/LC_MESSAGES/blender.mo` ของ Blender ที่ติดตั้ง
- `manual` — วลีที่เรียบเรียงเพิ่ม รวมคำศัพท์ทางเทคนิคแบบทับศัพท์
- `glossary` — ประกอบคำจากอภิธานศัพท์ อาจต้องปรับสำนวนตามบริบท
- `generated-summary` — สรุปภาษาไทยจากชื่อและชนิดข้อมูล ไม่ใช่คำแปลคำอธิบายอังกฤษทั้งประโยค

หน้าคลังแสดงที่มาชื่อและคำอธิบายต้นฉบับ ไม่เปลี่ยนรหัส native/operator จริง ภาพตัวอย่างและไฟล์โมเดลจึงยังสร้างด้วย Blender

ไฟล์อภิธานศัพท์ `engine/thai_glossary*.json` และข้อมูล `engine/blender_api.json` อยู่กับแอป แก้คำแปลแล้วสแกนใหม่เพื่อสร้างคลังของเครื่องนี้ ผลสแกนอยู่ `UserData/ApiCatalog` และใช้กับ runtime โดยอัตโนมัติ การเปลี่ยนชื่อในอภิธานศัพท์อาจเปลี่ยนชื่อ alias ที่แทรกใหม่ แต่ ID อังกฤษยังคงเดิม

## ความครบถ้วนที่ตรวจได้

สคริปต์ทดสอบเทียบรายการคำสั่งทั้งหมดกับ `dir(bpy.ops)` และชนิดข้อมูล/สมาชิกกับ RNA ของ build ที่ติดตั้ง โดยไม่นับสมาชิกสืบทอดซ้ำ เก็บไว้ที่ชนิดต้นทางและมี parentType เชื่อมโยง

ขอบเขตนี้ไม่รวม native functions ที่ไม่มี Python binding, ส่วนเสริมของผู้ใช้ที่ยังไม่เปิดใน factory-startup, สมาชิกของ object ที่สร้างขึ้นเฉพาะ runtime ทุกชนิด และการทดสอบพฤติกรรมทุกคำสั่ง UI ของ WinForms ยังเป็น editor/catalog/mesh preview ไม่ได้สร้างหน้าต่างและ renderer ทุกแบบของ Blender ใหม่

การตรวจ REA เดิมยืนยันตัว executable และ resources ส่วน catalog นี้เป็นการตรวจ runtime API พร้อม provenance แยกชัดเจน **ไม่มีการอ้างว่า decompile native modeling kernel แล้ว**

