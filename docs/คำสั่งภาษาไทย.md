# คำสั่งสร้างโมเดล

ฟังก์ชันเหล่านี้ใช้ได้ทันทีใน editor ไม่ต้อง import และคืนค่าเป็น object/material ของ Blender จริง นำ object ไปใช้กับ `bpy` ต่อได้ ชื่อพารามิเตอร์ใช้ภาษาอังกฤษ แกน Z คือความสูง หน่วยตั้งต้นเป็นเมตร

| ภาษาไทย | ภาษาอังกฤษ | พารามิเตอร์สำคัญ |
| --- | --- | --- |
| `ล้างฉาก()` | `clear()` | ลบวัตถุในฉากของ process ที่กำลังสร้าง |
| `วัสดุ(name, color, roughness=0.45, metallic=0)` | `material(...)` | `color` เป็น `#RGB`, `#RRGGBB`, `#RRGGBBAA` หรือ tuple RGB/RGBA แบบ linear ค่า 0–1 |
| `กล่อง(name, size=(1,1,1), location=(0,0,0), material=None)` | `cube(...)` | ขนาดเต็มตามแกน XYZ หรือค่าเดียวทั้งสามแกน |
| `ทรงกลม(name, radius=1, location=(0,0,0), material=None, segments=32, rings=16)` | `sphere(...)` | รัศมีและความละเอียด |
| `ทรงกระบอก(name, radius=1, depth=2, location=(0,0,0), material=None, vertices=48)` | `cylinder(...)` | รัศมี ความสูง จำนวนด้าน |
| `กรวย(name, radius=1, depth=2, location=(0,0,0), material=None, vertices=48, radius_top=0)` | `cone(...)` | รัศมีล่าง/บน ใช้สร้างกรวยตัดยอดได้ |
| `วงแหวน(name, radius=1, thickness=0.25, location=(0,0,0), material=None)` | `torus(...)` | รัศมีหลักและรัศมีท่อ |
| `พื้น(name, size=10, location=(0,0,0), material=None)` | `plane(...)` | ระนาบสี่เหลี่ยม |
| `ย้าย(obj, location)` | `move(...)` | กำหนดตำแหน่ง XYZ แบบ absolute |
| `หมุน(obj, degrees)` | `rotate(...)` | กำหนดการหมุน XYZ เป็นองศา |
| `ปรับขนาด(obj, size)` | `scale(...)` | ตั้ง scale เป็นค่าเดียวหรือ tuple XYZ |
| `ทำซ้ำ(obj, name=None, location=None)` | `duplicate(...)` | สำเนาวัตถุและข้อมูล mesh แยกกัน |
| `ขอบมน(obj, width=0.1, segments=3)` | `bevel(...)` | เพิ่ม Bevel modifier |
| `ผิวเรียบ(obj)` | `smooth(...)` | smooth shading (viewport รุ่นนี้ยังแสดงแสงต่อหน้าสามเหลี่ยม) |
| `ตัดรวม(obj, cutter, operation='DIFFERENCE', hide_cutter=True)` | `boolean(...)` | Boolean แบบ `DIFFERENCE`, `UNION` หรือ `INTERSECT` |

## ตัวอย่าง Boolean

```python
ล้างฉาก()
สี = วัสดุ("โลหะฟ้า", "#69AADD", metallic=0.5)
ชิ้นงาน = กล่อง("กล่องเจาะรู", size=(3, 3, 2), location=(0, 0, 1), material=สี)
ตัวตัด = ทรงกระบอก("ตัวตัด", radius=0.65, depth=4, location=(0, 0, 1))
ตัดรวม(ชิ้นงาน, ตัวตัด)
ขอบมน(ชิ้นงาน, width=0.07, segments=3)
```

## Blender Python โดยตรง

```python
import bpy
ล้างฉาก()
bpy.ops.mesh.primitive_monkey_add(location=(0, 0, 1))
หัวลิง = bpy.context.object
หัวลิง.name = "หัวลิง"
ตัวปรับ = หัวลิง.modifiers.new("เพิ่มความละเอียด", 'SUBSURF')
ตัวปรับ.levels = 2
หัวลิง.data.materials.append(วัสดุ("สีม่วง", "#9F7FE8"))
```
